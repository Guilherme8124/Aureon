## 🗄️ Banco de dados

O projeto utiliza o **Supabase** como backend e banco de dados.

Entre os dados que podem ser administrados estão:

```text
Projetos
Artigos
Notícias
Mensagens
Leads
Configurações
Usuários
```

As credenciais sensíveis não devem ser armazenadas diretamente no repositório público.

### ⚠️ Segurança

Nunca publique no GitHub:

```text
SUPABASE_SERVICE_ROLE_KEY
Senhas
Tokens privados
Chaves secretas
Credenciais administrativas
```

Chaves públicas, como a `anon key` do Supabase, devem ser utilizadas de acordo com as regras de segurança e políticas de acesso configuradas no banco.

## 💻 Como executar localmente

### 1. Clone o repositório

```bash
git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
```

### 2. Entre na pasta

```bash
cd Aureon
```

### 3. Execute o projeto

Como o projeto utiliza tecnologias web front-end, você pode abrir:

```text
index.html
```

diretamente no navegador.

Para uma experiência de desenvolvimento mais adequada, recomenda-se utilizar um servidor local, como o **Live Server** do Visual Studio Code.
